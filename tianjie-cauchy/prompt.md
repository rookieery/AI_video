- **凡阶**（初中）：a²+b² ≥ 2ab、√(ab) ≤ (a+b)/2

- **a 向量一侧 = 金色**（#e8b64c / 高亮 #ffd76a）

### 4. 通用组件类（shared.css）

- `.sym{display:inline-block;opacity:0}` —— 公式符号的初始隐藏态，配合 reveal 逐个亮起
- `.gold/.cyan/.muted/.gold-hi/.cyan-hi` 颜色类；`.frac` 分数（上下结构，下划线为分子分母隔线）
- `.panel` 半透明圆角面板（1px 边框 rgba(255,255,255,.16)，圆角 20px）
- `.chip` 胶囊标签（圆角 999px）
- `.stamp` 印章：4px 金色边框、圆角 14px、字距 .1em、外发光 46px rgba(255,215,106,.35)
- `.p` 粒子基类（绝对定位圆点）

### 5. 动效语法（全片反复出现的「习语」，必须沿用）

1. **逐符号揭示**：`F.reveal(root, t, start, step, dur)` —— root 内每个 `.sym` 依次 opacity 0→1 + 上浮 16px 缓出。
2. **「≤ 重击」punch**：关键时刻 ≤ 缩放至 ~1.32、变金、加金色 text-shadow 发光；同时白色闪屏 0.16–0.22、粒子爆发、1–2 圈扩散金环、下方金色下划线 scaleX 扫过。
3. **取等印章**：金框印章文字（如「取等 · 共线」）旋转 −6° 盖下，配白闪+爆发，场景结束前淡出。
4. **场景退场**：上浮 + 模糊（snap exit），而非简单淡出。
5. **发光呼吸**：结论公式背后 radial-gradient 光晕以 sin ~3Hz 呼吸。
6. **确定性**：所有粒子/散点用带种子的伪随机 `F.rng(seed)`，各镜固定种子（见各镜），保证任意 t 画面可复现。

## 三、技术架构（必须按此搭建）

1. **OpenFilm 胶片结构**：`film.html` 为剪辑台，viewport 1920×1080，body 背景 `#05070d`；单个 `<section>`（一条轨道）依序排 8 个 `<iframe>` 片段（剪辑表见第七节）。
2. **一镜一页**：每个镜头是独立 HTML 页面，加载 shared.css 与 shared.js，设置
   `window.film = { duration: <秒>, frame(t){…} }`。**画面只依赖 t**（纯函数，无自驱动画、无 autoplay）；页面无自身 width/height（即整幅 1920×1080 舞台）。
3. **shared.js 工具库 `F`**（新项目需实现相同 API）：
   - `seg(t,a,b)`：把 t 夹取为 [a,b] 内的 0–1 进度；`lerp(a,b,u)`
   - 缓动：`eoc`（三次出）、`eic`（三次入出）、`eob`（back 过冲，c=1.70158）、`eoq`（四次出）
   - `rng(seed)`：mulberry32 风格确定性伪随机

   - `reveal(root,t,start,step,dur)`：逐符号揭示（见上）
   - `makeBurst(host,x,y,n,seed,color,rMax)`：n 粒径向爆发，返回 `{update(t,t0,dur)}`
   - `makeRise(host,x,y0,h,n,seed,color)`：列内持续上升光尘，返回 `{update(t)}`
4. **无音轨**：整部影片没有任何 `<audio>`/`<video>`，纯页面动画。
5. **无外部素材**：不引用任何图片/字体文件；曲线、坐标系全部 SVG/CSS 代码绘制。
