## 2. 无缝铁律（拼接零缝）

- **片内时间 = 对弈片 t + T_OPEN(16.0)**：`window.film.frame = gt => frame(gt + T_OPEN)`，对弈 t=0 逐像素 ≡ 开场末帧（v1.9 开场扩时 16s 后拼缝 diff 0.53%/max191/mean0.0069，同基线噪声级；星野旋转/取子台呼吸/光锥闪烁/旋柱自转相位全部连续）。
- 相机**静机位持镜**：camAt 的 remap 自带钳制，t≥14.0 恒停在末键 (0,3.60,0.32) 俯视 85°，不加任何新相机键。
- **轮廓光青系（双片统一）**：对弈片与开场片 `rimL` 统一 `0x1FC8E0`（原风格 a 绯红 `#FF4D74` 在近景白子上读作染红；v1.0.1 对弈片先换，v1.0.2 开场片同步换青重渲为 v1.8，拼缝高光完全一致）。
- 坐标系同 prompt.md §4：天元 (0,0)，+x 右 +y 上；世界坐标 `x=gx*S, z=-gy*S`（S=0.15 格距）；落子定格高度 `y=0.012`（与花月三子一致，含 rim 光圈与软影）。
- **禁改开场部分任何闭式**；S7 新增状态全为 t 的纯函数（无累积、无随机）。

## 3. 单手节拍（v1.2：PERIOD=2.1s，×0.875 顺缩；v1.1 定稿 2.4s）

u = t − 手起点（手 k 起点 = T_OPEN + k·PERIOD）：

| u（s） | 动作 |
|---|---|
| 0.09–0.26 | 蓄势：本色盒柱顶子微升 0.05 + slotGlow 预亮（scale 0.22，op≤0.4） |
| 0.26–1.36 | **单段抛物线飞行（v1.2 缓动改型）**：全航迹唯一一段——水平 **inCubic 先慢后快**（前半悬停似思考、末段加速果断落子，替换 v1.1 inOutCubic 匀顺感），竖直 `lerp(y0,STONE_Y,e)+MV_ARC·4e(1-e)`（拱高 0.60，拱顶因 ease-in 后移至航时 ~79%）；飞子辉光按航时 55%→95% 渐隐（改按时间解耦，inCubic 下进度式渐隐会压缩到最后 ~0.1s 过陡）；v1.0 双停顿根因=拔起/飞行/坠落三段 ease 在 0.75/1.35 接缝双零速度，单段后数学上无内部接缝 |
| 1.36 | **落子定格**（棋子恒久）：inCubic 末速最高→触板干脆（"立即落子"）；软影落前 0.5s 渐入；**最新子高亮** 0.15s 渐入至 op 0.40 常亮（v1.1 删波纹环+落点闪光，防连续落子光污染） |
| 下一手 0.26 | 取子瞬间：上一手高亮 0.2s（`MV_HL_OUT`）渐出让位还原；**末手高亮持续到片尾** |
| 1.62–1.88 | 补子：柱顶 outBack 弹出新子 + slotGlow 回闪；柱恒 6 颗 |
| →2.10 | 收静回待机（其余 5 颗与全部呼吸相位不受影响） |

## 4. 机制要点

- **取子源**：`BOWL_MODE='holo'` 柱顶第 6 颗（`SLOT_I=5`，构建式 `a=5*2.35+0.5, rr=0.115+(5%2?0.035:0)=0.15, ty=0.075+5*0.03=0.225`，呼吸 `slotBob(t)` 与 holo 块同式；**旋柱半径/层高改动时引擎 SLOT_* 必须同步；柱全程自转 `col.rotation.y=0.22t` → 取子/辉光世界角=SLOT_A−0.22t（飞子起飞点冻结于取子瞬间 `ta=T_OPEN+k·PERIOD+0.26`，slotGlow 实时跟随；v1.1 修复取子横跳 ~180°）**；柱顶子经近俯视外扩略越锥口属定版观感——v1.0.1 曾收紧半径，用户回退：收紧后旋柱太挤，宁保舒展）。黑盒 `bowlC.items[0]` / 白盒 `items[1]`，按 `MOVES[k].c` 取对应盒。
- **MOVES 格式**：`{c:'B'|'W', x:int, y:int}`；黑白轮流由数据自证，引擎不做规则校验。
- 片长 = `MOVES.length × PERIOD + END_DUR`（END_DUR=检出胜负时的退场段，见 §8）；**game/film.html 的 hash `#t=0,N` 与 `game.html` 内 `DUR`（文件头，含 END_DUR）两处必须同步**（本版 PERIOD=2.1，当前 12 手 + dust 退场 4.0 = 29.2）。
- 高亮晕/软影每手一套（flash 精灵复用）：**最新落子高亮** op 0.40（`MV_HL`）常亮，下一手取子瞬间 0.2s 让位；落子棋子与软影按手数永久累加；v1.1 已删波纹环（mvRipple）。

## 5. game.html 生成与渲染（工程坑）

- 生成：拷贝 starcodex.html → ①title ②import 改 `./game-config.js`（含 MOVES/PERIOD）③`const T_OPEN=16.0; const DUR=T_OPEN+MOVES.length*PERIOD`（frame 首行钳制用）④`composer.render()` 前插 `updateMoves(t);` ⑤`window.film` 的 duration/frame 改为 `MOVES.length*PERIOD` / `gt=>frame(gt+T_OPEN)`；S7 引擎插在 window.film 注释前。**开场片时间常数一改（如 v1.9 扩时），game.html 内嵌的开场时间轴必须同步重打同批补丁（约 25 处），否则对弈片背景仍在跑旧节拍。**
- **openfilm 页面必须位于项目文件夹内**（film.html 引 `../game.html` 报 "there is no such file"）→ 渲染对弈片用**临时换入法**：备份 film.html → 写入 `src="game.html#t=0,N"` → `npx openfilm render --out game/xxx.mp4` → 立即还原 film.html（防覆盖开场成片，--out 必带）。
- **透明排序坑（2026-10-26 w4b5w6b7 发现）**：`flash`/`flyGlow`（RO0）与 `boardBase`（透明 2.5×2.5 大平面，RO0，原点在 (0,0)）同队列按相机距离排序——落子点距原点超过临界圆（r≈0.46，随相机高变）时 flash 比棋盘远、先画，被棋盘 α≈0.94 正常混合整体盖死（高亮晕消失；石子不透明/软影 RO2/rim RO6 不受影响）。历史 MOVES 全部 r≤0.424 从未触发，白10 (-1,3) 首次越界。**修法：flash/flyGlow `renderOrder=1`**（棋盘 0 之上、软影 2 之下）。新_MOVES 若含 r 更远坐标无需再改；同理任何新增 RO0 透明特效注意与 boardBase 的距离序。
- QC：`npx openfilm look game.html <t>` 可直接抽帧单页（无需换入）；确定性双绘 + 首帧 vs 开场末帧逐像素 diff。

## 8. v2.0 五连特效 + 退场（2026-10-26 定稿：`WIN_FX='beam'` + `EXIT_MODE='dust'`）

- **取胜检测（game.html 文件头，导入期一次）**：开局三子（黑1 天元 + 白2/黑3 查 openings 表）+ `MOVES` 逐手落图，四轴（横/竖/两斜）任一连五即胜，取最早胜手；`WIN_AT`（MOVES 下标）可手动覆盖。当前 12 手 → 黑15 检出 y=0 横五连（全局手序 i=14，含天元）。`END_DUR`（片尾追加）= 检出胜负才有：dust 4.0 / arc 4.6 / train 5.4，`END_SEC>0` 可强制。
- **S8 五连特效（对弈片时间轴，T0=胜手落定+0.12）**：自胜子向两端逐子点火（0.14s/子，光环+落点扩散环）→ TD0=T0+0.62 起 0.55s 光轨绘制（高饱和青激光主轨 + 白热芯线 + 盘面底光带，端部外吐 0.17，彗头引导）→ 保持段呼吸+光珠沿轨巡游（1.2s 循环）。**配色按胜方：黑=冰青 (#04C7E8/#9BEEFF) / 白=暖金香槟 (#E8C25A/#FFE9B8)**。坑：加色+bloom 下芯线必须高饱和彩色，白芯与棋子白热辉光同质读不出。
- **S9 退场（T_X0≈26.08 = TD0+绘制+0.33 与片末取大）**：`'dust' 星尘回流`（选定）——棋子按逆布局序每 0.13s 一子原地溶解（0.3s 缩没+光痕沿弧线 0.5s 飞回本色柱顶，目标实时跟随旋柱零跳变），盒位吸收闪光+柱身脉冲；开局三子走 miniBoard 局部系（世界→局部 = (X,−Z,Y)）；软影/最新子高亮随子离盘渐隐；终拍盘框+天元微光缓暗一档（窗口 T_END−1.3 → T_END−0.6，随 END_DUR 定位）。备选：`'arc'` 逆序逐子抛物线归台（4.6s）/ `'train'` 胜五压编队先行飞盒+余子接续（5.4s，队形镜头最出彩）。变体对比图 `_qc/v/sheet-*.png`。
- **片长**：12 手 + dust = **29.2s**（game/film.html hash `#t=0,29.2` 已同步）。换 END 变体须同步 hash。
- **架构坑（重申）**：`frame(t)` 内部钳制 `t=Math.min(DUR,…)` 的 `DUR` 在 game.html **文件头**（已含 END_DUR，检测也因此提前到文件头）——改片长只动 window.film.duration 不动 DUR 会把新片尾全部吞掉；诊断手法=页面注入可见 t 计数器抓帧读真实时刻。新增透明特效 renderOrder=1（boardBase RO0 之上、软影 RO2 之下，§5 排序坑同源）。

## 9. v2.1 活三光轨（2026-10-26 定稿已渲染：`LIVE3_FX='beam'`）

- **事件检测（game.html 文件头 `L3_EV`，导入期一次）**：自每手新子沿四轴扫 7 种 pattern（连活三 3 + 跳活三 4，见 PATS 表），且**下一手确实落在堵点**（端点或缺口，`dot` 须除以 `dx²+dy²` 归一为线参 j——斜轴 |d|²=2 不归一必漏检）才成立；配色不分检测方、随三子方：黑=冰青 / 白=暖金（同五连语义）。`LIVE3_SKIP`（game-config.js）按「成三手」MOVES 下标排除复合形——黑13(下标9) 是四三，四三特效后续单独做。当前 4 事件：k=4 白8 堵黑7 横三、k=6 白10 堵黑9 斜三、k=8 白12 堵黑11 竖跳三缺口（双束）、k=11 黑15 堵白14 竖三（暖金）。
- **S7.5 播放（内嵌堵点那手 PERIOD 窗，与飞子同拍）**：0.26 光束自端子亮起 → inCubic 扫过三子（与飞子同缓动同步加速，无逐子点火，途经子仅瞬时增亮）→ 1.36 尖端抵堵点、对方子落定「封光」（撞击闪光+盘面扩散环）→ 1.46–2.02 星光自堵点回流端子+渐熄；跳三被堵缺口=双束两头汇聚、被堵端点=单束朝被堵方向。窗口外全隐藏，总时长零影响。
- **大坑（本次两伪影同根因）**：光束几何 `PlaneGeometry(L,w).translate(L/2,0,0)` 已按 L 建好，`scale.x` 必须用纯比例 d（同 S8），尖端世界距离另算 `d*L`——误用 `scale.x=d*L` 长度变 L²·d，束长<束宽时残余宽度读成垂直细线（横束出竖痕/竖束出横线）。定位手法：`LIVE3_FX=null` 基线 A/B 同帧对比。
- **QC 通道**：game/ 下 `npx openfilm look ../game.html <t>`，t=对弈局部时刻，事件窗口 k*2.1~(k+1)*2.1。已知无害坑：每手窗口尾段（u≥~2.0）look 报非确定性警告，v1.9 起就有、与活三无关、不影响成片渲染。
