## 一、任务总览

**主题一句话定位**：面向数学科普爱好者（3B1B 向）+ 抖音路人的基本不等式直觉动画——一句"平方非负"拆出 a²+b²≥2ab，代换后让 √(ab)≤(a+b)/2 在一张直径 20 的半圆弦图上现出原形：半弦拼命长，只在圆心那一瞬碰到半径；篱笆悬案首尾闭环，顺手点亮凡阶星点、反望天阶柯西。

**核心理念**：全片以「弦追半径」为脊柱——先立悬案（篱笆）、再出砖（平方非负）、再换装（两个平均）、再看戏（半圆名场面）、再审判（扫描封顶）、再正名（金匾一行证明）、再点灯（星轨竞猜收束）。**公式是被等到的，不是开场甩出来的。**

**叙事结构**：线性六镜 + 首尾闭环（S0 的「面积差5倍多」悬案 → S2 弦上缺口 81=((19−1)/2)²（即 ((a−b)/2)²）→ S3 兑付 100−19=81）；修仙阶位世界观（凡/地/天/神）仅 S4 金匾小字与 S5 星轨点缀。

## 三、技术架构

1. **胶片结构**：film.html 为剪辑台，viewport 1920×1080，body 背景 #05070d、margin 0；单个 `<section>`（一条轨道）依序 6 个 iframe（剪辑表见第六节）。
2. **一镜一页**【H9】：s0–s5 各为独立 HTML，加载 shared.css 与 shared.js，实现 `window.film = { duration:<秒>, frame(t){…} }`；页面不设自身 width/height（整幅舞台，绝对像素坐标）。
3. **纯函数渲染**【H10】：画面只依赖 t。禁止 rAF/setInterval 驱动画面、禁止 CSS animation/transition 呈现可见变化、无 autoplay；一切状态由 frame(t) 直接计算（呼吸/闪烁等以 sin(t) 表达）。
4. **工具库**【H12】：shared.js API = seg / lerp / eoc / eic / eob / eoq / rng / fmt / reveal（保留能力，本片禁用）/ makeBurst / makeRise / capShow / token；**公式排版能力（H28）**：`.fx-row`/`.frac`/`.surd`/`.sup`/`.sub` 样式集中 shared.css，token 高亮/morph 在容器内 transform 实现；本片 HUD（S1 读数列/S3 记分牌/S2 追跑条）各页自建（v2 的 makeHUD 为柯西特定件已剔除）。
5. **确定性**【H11】：一切随机走 F.rng，种子入档：S0 星点层 3、S2 白闪爆发 21、S3 顶点粒子 5、S4 金尘 11 / ∎ 爆发 13、S5 星尘 2023。
6. 绘制分工：曲线/坐标系/路径优先 SVG，文字卡片用 DOM；全片以秒为单位，页面 t 从 0 起，影片时间 = 片段累计。
