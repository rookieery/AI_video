**关键词**：深空星野、黑曜石、暗金压印、漆器嵌金、吸积盘、体积辉光。

| 用途 | 颜色 |
|---|---|
| 深空底 | `#04060E → #0A0F1E` 径向渐变 |
| 星光 | 暖白 `#F5EFE0`（约3%，金 `#E8C96A`） |
| 暗金主光/高光 | `#C9A227` / `#E8C96A` |
| 绯红点缀/亮绯红 | `#B03A2E` / `#FF6B52` |

**v1.1 赛博朋克配色（STYLE='a' 霓虹棋谱）**：语义不变——直指主色 = 青 `#04C7E8`，斜指辅色 = 洋红 `#F43F5E`。深海军蓝底 `#050A14→#0C1B31`；星空冷白青；棋盘底部深蓝面板 + 压暗青网格（`#0E90A8`），终版嵌青色圆角霓虹框；书封改 PCB 电路（地纹网格 + 正交走线 + 焊点 + 芯片块 + 虚线仪表环），书页冷青；星位由金菱形改为青色发光圆点；吸积盘洋红→青。原暗金版保留为 `STYLE='gold'`，可随时切回。

**v1.2 半透明封印书（BOOK_STYLE='seal'）**：封面中央为青色点阵，四颗实体黑曜棋子按 45°/135°/225°/315° 菱形环列，每颗套一圈洋红/绯红能量焰，外围一圈缓慢旋转的能量封印环；玻璃封面、书页、封底均为半透明，配内部辉光、书页亮线、右缘导光与竖向反光，星空可隐约透出。备选 `'holo'`（线框棋子+矢量弧+扫描线，最轻透）与 `'circuit'`（刻蚀虚线圈+方形焊盘+暗内衬，最仪器感）。

## 3. 分镜时间轴（六幕，精确到0.1s）

### S1 星空浮书（0.0–2.2）
- 星野：种子随机 3000+ 星点 + 2 层远景星云（加色混合），整体绕 Y 轴缓旋；相机从侧向远景缓推近书。
- 书：深色书皮悬浮于画面中心偏下，正弦浮动 ±0.05、慢速自旋 ±4°；书脊朝左竖立。
- 封面（v1.2 半透明封印书）：**四颗黑曜棋子**按 45°/135°/225°/315° 环绕成圆，各套洋红能量焰（独立自转、呼吸周期 1.6s、相位依次差 0.4s）；中央**青色点阵**（慢速反转、随呼吸微亮）；外围**能量封印环**缓慢旋转。玻璃封面半透明，可透见内部辉光、书页亮线与星空。
- 1.6–2.2：呼吸加速、整体亮度爬升（铺垫激活）。

### S2 自动激活翻开（2.2–3.4）
- 2.2–2.6：封面脉冲发光两次（每次 0.2s）；书脊金线亮起并向两端蔓延。
- 2.6–3.4：封面绕书脊翻 0°→178°（easeInOutCubic），翻页拖尾金色粒子。
- 3.0（翻开过半）：书页缝溢出**青色能量线**（窄幅低辉光，亮度压至 0.26 忌爆白；bloom 峰值降为 1.06）。
- 3.2–3.4：书体下沉让位。

### S3 26卡双弧成阵（3.4–6.4）
- 3.2–3.85：**双螺旋星门织门**——青（直指族 `#9BEEFF`）/ 绯（斜指族）两根霓虹细螺旋（半径 0.28、高 2.3、2.6 圈）自书心反向旋转升起，细管径吃 bloom 呈灯管质感。
- 3.42–3.75：门顶凝出**小亮核**（0, 2.55, 0，直径约 0.11）；3.95–4.6 双螺旋解旋消散（尾端上滑+淡出），**不留残柱**，中心清空给 S4 黑洞。
- 3.7–6.0：26 张卡片依次从亮核飞出，沿螺旋+贝塞尔路径（控制点外扩制造盘旋感）飞往弧位；**错峰 70ms/张**，单张飞行 0.55s，落位 easeOutBack 轻微过冲回弹；每卡离核瞬间拽出一缕同族色光丝（直指青/斜指绯，0.3s 消散）。出卡顺序：直指 13（按§4表序）→ 斜指 13。
- 弧阵几何：**直指弧** = 左上弧（暗金描边卡）；**斜指弧** = 右下弧（绯红描边卡）；两弧弧心角约 150°、半径 3.2，卡面朝镜头并绕弧切线微倾约 12°；**两弧之间留出中央空洞**（S4 黑洞预留位）。卡尺寸约 0.72×0.72。
- 6.0–6.4：全阵待命微漂浮（每卡正弦相位错开），一道扫光从两弧外端掠向中心。

### S4 太极归一淘汰（v1.4 时间 7.1–8.9；v1.5 机制）
- 7.1–7.4：中央空洞处**太极盘**张开（easeOutQuart）——暗青气场底盘 + 青（直指族 `#04C7E8`）/绯（斜指族 `#F43F5E`）双臂逗号形能量盘（互嵌 180°，各含彼色鱼眼），头朝上顺时针旋转；中央小黑核 + 细白光环。
- 7.4–8.7：25 卡逐张淘汰，**从两弧外端向内序贯**：翻面 180°（0.15s）→ 变暗去饱和 → 引力拉丝 → **顺时针螺旋吸入**（与太极旋向同向，0.35s）；节奏递增（卡间隔 90ms→55ms）；**直指卡汇入青臂、斜指卡汇入绯臂**，每吞一张对应臂体短暂增亮（族脉冲）；族色碎屑散落又被吸回。
- 8.5–8.7：**归一**——双臂收拢合色（青绯→白青）、转速徒增，白青核闪渐起。
- 8.7–8.9：太极收拢消失，核闪绽放，一圈星尘径向吹散。
- **花月卡（直指弧第4位）全程保留**，7.4 后缓缓移向阵前中央，恰在太极归一的中心。
- 备选机制（`ELIM_MODE`）：`'singularity'` 全息坍缩（黑洞结构不变，吸积盘换青蓝全息谱+青照明）/ `'ring'` 星环收束（细霓虹环+25颗族色光珠绕环公转，环连珠向心收束）/ `'hole'` v1.2 粉盘基线。

### S5 花月定格（8.2–9.2）
- 8.2–8.8：花月卡飞向镜头（+Z 1.8）并旋正（roll→0），放大至屏高约 52%。
- 8.8–9.2：金色描边扫光一周（0.35s），卡片轻微呼吸。

### S6 网格生长 E1：5×5 → 15×15（9.2–12.0）
- 9.2–9.5：**卡框溶解**——描边扫光后淡出，卡底透明度→0，只留 5×5 网格与三子悬浮原位。
- 9.5–11.5：**波前生长**——金色谱波前（方形环带）自天元向外扩 5 圈（半径 3→7，即 15×15 边界），圈时长先快后慢：0.28 / 0.32 / 0.38 / 0.46 / 0.56s；波后 0.05s 内新线段从内向外凝出；波前扫过每颗棋子时该子弹亮 0.1s；波前扫过 ±4 星位时四个星位金标凝出。
- 相机同步：9.5 近距低角（俯角≈20°）→ 11.5 俯角≈85° 接近正俯视，始终框住当前生长边界。
- 11.5–12.0：正俯视定版，15×15 居中占屏约 82%，天元微光呼吸一次，四角暗角轻收。**无任何文字**。
- 大盘：15×15 交叉点，漆器深底嵌金线；星位 5 点（天元 + (±4,±4)）小菱形金标。

## 5. 卡片视觉规格（无名称版）

## 6. S6「网格生长 E1」无缝原理（实现铁律）

**迷你 5×5 即大盘中央 5×5，格距全程不变**——前三手所在交叉点在两盘中是同一组世界坐标点，故棋子零位移、天然无缝；生长只是向外新增线段，不是缩放变换。禁用任何整体 scale/位移动画来实现展开。

## 7. 技术架构规范（OpenFilm + three.js）


- `window.film = { width:1920, height:1080, duration:12, ready:Promise, frame(t) }`。
- **frame(t) 纯函数铁律**：一切可见状态由 t 派生；星空/粒子属性用固定种子 PRNG（mulberry32）一次性生成；禁止 rAF 累积、Date.now、Math.random。
- 相机：关键帧位 + Catmull-Rom 插值 + 各幕缓动表；FOV 42°。
- 卡片纹理：offscreen canvas 程序化绘制 26 张（`drawMiniBoard(ctx, opening)`），ready 前生成完毕；无任何外部资源，全程序化可复现。
- 后期：UnrealBloom（按调色板设定；A 版 strength 0.82 / threshold 0.52 / radius 0.62）+ 扫描线/色差/故障 ShaderPass（A 版色差 0.8、无扫描线；S4 黑洞张开 6.40–6.50 与 S6 定版 11.46–11.56 各 0.1s 轻故障）+ 确定性暗角。
- QC 抽帧清单（v1.4 时间）：0.0 / 1.1 / 2.2 / 3.0 / 3.7 / 4.8 / 5.9 / 6.5 / 7.05 / 7.4 / 7.8 / 8.3 / 8.6 / 8.85 / 9.3 / 9.7 / 10.5 / 11.5 / 12.9。
- 渲染：`openfilm look` 逐帧质检 → `openfilm render`（1920×1080 / 30fps / 无音轨）。

## 9. 后续视频复用（换开局）

仅改 `config.js` 的 `SELECTED`：S4 保留卡、S5 定格卡、S6 三子坐标全部自动查 `openings.js` 切换（黑3 与白2 方位随直/斜指自动变化），其余分镜零改动。视觉机制另有三处一行开关：`STYLE`（成片风格）、`TRANSITION`（S2/S3 书→卡转场机制，v1.3 定稿 `'helix'`）与 `ELIM_MODE`（S4 淘汰机制，v1.5 定稿 `'taiji'`）。
