## 一、任务总览

**主题一句话定位**：面向数学科普爱好者的柯西–施瓦茨不等式直觉动画——用「影子，不会比杆长」一句话讲透一个天阶公式，修仙世界观只在首尾点缀。

**核心理念**：全片以影子为脊柱——先看懂（影子）、再读式（手写）、再验证（63 vs 65）、再证明（距离² ≥ 0）。**公式是被等来的，不是开场甩出来的。**

**叙事结构**：线性六步（直觉→读式→验证→正名→推广→证明）+ 收官回收；修仙阶位（凡/地/天/神）作为系列世界观仅出现于 P3 金匾与 P6 星轨。

## 三、技术架构

1. **胶片结构**：`film.html` 为剪辑台（OpenFilm 约定文件名；项目目录已隔离 v1/v2，无需 -v2 后缀），viewport 1920×1080，body 背景 #05070d、margin 0；单个 `<section>`（一条轨道）依序排 7 个 iframe（剪辑表见第六节）。
2. **一镜一页**【H9】：p0–p6 各为独立 HTML，加载 shared.css 与 shared.js，实现 `window.film = { duration:<秒>, frame(t){…} }`；页面不设自身 width/height（整幅舞台，绝对像素坐标）。
3. **纯函数渲染**【H10】：画面只依赖 t。禁止 requestAnimationFrame / setInterval 驱动画面，禁止 CSS animation / transition 呈现可见变化，无 autoplay；一切状态由 frame(t) 直接计算。
4. **工具库**【H12】：沿用 v1 shared.js 全部 API（seg / lerp / eoc / eic / eob / eoq / rng / fmt / reveal / makeBurst / makeRise；reveal 保留能力但本片禁用）；新增：记分牌 HUD 组件（状态机 grow→freeze→dock→recall）与 token 高亮（整式内指定符号按 (start,dur) 依次提亮微放大）。
5. **确定性**【H11】：一切随机走 F.rng，种子号入档：P1 爆发 21、P3 金尘 11、P4 散点 9 / 趋势 5、P5 爆发 13、P6 星尘 2023。
6. 绘制分工：曲线/坐标系/路径优先 SVG，文字与卡片用 DOM；全片以秒为单位，页面 t 从 0 起，影片时间 = 片段累计。
