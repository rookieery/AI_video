## 二、分镜 beat sheet

### P0 冷开场（0–10s）「影子能比杆长吗」
- **0–3s** 黑场，一道光锥自右上打下；金杆 a 立起，橙影随即拉出。大字幕：**「影子，能比杆长吗？」**（第 3 秒起就有参数运动，不是标题动画）
- **3–10s** 杆微动、影随伸缩（连续运动贯穿）；字幕：「数学里有个不等式，说的就是这件事。」
- 公式 0 · 白闪 0 · BGM 锚点：0s 起拍 / 3s 光效 / 10s 转场
- 备选钩子（若不用 A）：B 数字悬念「63²=3969，但 65²=4225——多出的 256 是什么？」；C 历史钩子「一个不等式，三个人，三个国家，67 年」

### P1 影子为纲（10–52s，42s）——全片心脏
- **10–16s 布景**：金杆 a=(3,4)（标长度 5）、青杆 b + 方向虚线；字幕：「把它们看成两个向量。」
- **16–24s 影子登场**：橙影沿 b 方向长到 4.85；标尺面板（杆长 5.00 恒定 vs 影子实时）；垂线=光线（明示"光垂直打过去"，防"长影"误解）；字幕：「影子 = 杆长 × cos 夹角」
- **24–31s 取等**：θ 扫向 0°，影子 4.85→5.00；重合瞬间**白闪①**+爆发+印章「取等 · 共线」；字幕：「夹角归零，影子追平杆长——这叫取等。」
- **31–40s 正交与负影**：θ 越过 90°，影子缩到 0（字幕：「垂直时，影子消失——两个方向毫不相干」）；**继续转，影子翻到原点另一侧、读数 −4.00**（带符号投影，画面论证 |·|，修复现版符号矛盾）；字幕：「转过 90°，影子躲到身后，成了负数。」
- **40–48s 桥+手写**：两边同乘 ‖b‖ → a·b = ‖a‖‖b‖·cosθ（影子×杆长 = 乘积之和）；**金笔手写** |a·b| ≤ ‖a‖·‖b‖（保留 ≤ 双侧挤压签名动作）；字幕：「影子不超杆长，写下来，就是它。」
- **48–52s 术语坡道**：字幕：「a·b 读作点积——对应相乘，再相加。」（为 P2 铺垫）
- 公式 2 · 白闪 1 · 印章 1 · BGM 锚点：24s 蓄力 / 31s 重拍 / 40s 手写独奏位

### P2 数值验证（52–75s，23s）
- **52–59s 同一对数回归**：胶囊 (3,4)、(5,12)（观众认出 P1 的两根杆）；活体代入：3×5+4×12=**63**、5×13=**65**（数字飞进式位，非逐符号揭示）；字幕：「算一次：乘积之和 63，模长之积 65。」
- **59–67s 双柱对决**：63²=3969 vs 65²=4225 同步生长，差距定格 **256**（色彩+缩放冲击，不用白闪）；**记分牌 HUD 落成右下角常驻**（去 PPT 化关键件：柱图从此不清场）；字幕：「差的 256，就是夹角的代价。」
- **67–75s 会师金句**：3969/4225 = (63/65)² = **cos²θ**（P1 的夹角与 P2 的数字会师）；一句话推广字幕：「换成 n 个数，结论不变。」（Σ 紧凑式**静态**出现一次，不做碎片动画）
- 公式 2 · 白闪 0 · BGM 锚点：59s 双柱起拍 / 67s 定格重音

### P3 天阶正名（75–92s，17s）
- **75–83s 金匾降下**：此刻才落金匾（品牌时刻——观众已认识公式的两个化身，公式是**被等来的**）；主公式 (Σaᵢbᵢ)² ≤ (Σaᵢ²)(Σbᵢ²) 整式入场；三人名一闪：Cauchy 1821 / Bunyakovsky 1859 / Schwarz 1880s（修年份表述）；字幕：「它叫柯西–施瓦茨不等式。」
- **83–92s 特例集锦**（原 S2 的灵魂压缩）：主式 token 高亮 → b=(1,…,1) 代入，式子滑变 (a₁+⋯+aₙ)² ≤ n(a₁²+⋯+aₙ²)；字幕：「n=3，就是你高中的 (a+b+c)² ≤ 3(a²+b²+c²)。」再一笔带过 a²+b²≥2ab、均值链（卡级小字，不展开）；字幕：「你背过的许多不等式，都是它的影子。」（**方向说对：特例，不是推导链**）
- 公式 2 · 白闪 0 · BGM 锚点：75s 金匾落定 / 83s 变形滑音

### P4 四件衣服（92–114s，22s）
- **92–97s 接入**：从 P1 正交姿态淡入 55 粒散点云；字幕：「两个毫不相干的量，数据里叫不相关。」
- **97–105s 相关系数**：金色趋势线穿云（**残差线染橙——还是影子！**）；字幕：「相关系数 ρ，就是夹角——永远在 −1 和 1 之间。」印章级呈现 |ρ| ≤ 1
- **105–114s 星碑流变**：同一位置连续换装 Σ（求和）→ ∫（积分）→ E（平均）→ ⟨,⟩（点积），每个符号配白话小标；字幕：「数列、函数、概率、向量——同一个定理，四件衣服。」
- 公式 3 · 白闪 0 · BGM 锚点：97s 换拍 / 105s 流变三连音

### P5 证明·距离不为负（114–136s，22s）——几何化重做
- **114–120s 问题**：字幕：「为什么影子永远超不过杆？」画面：b 方向线上一动点 t·b，到 a 的距离棒实时伸缩；字幕：「沿 b 走 t 步，什么时候离 a 最近？」
- **120–127s 本体**：f(t)=(3t−5)²+(4t−12)² = 距离² → 25t²−126t+169 抛物线贴轴呼吸；**顶点=垂足=影子端点**三重会师（顶点闪烁 ↔ 平面垂足闪橙连线）；字幕：「距离的平方，永不小于零——这就是全部证明。」
- **127–136s 兑付+升格**：Δ=−1024=**−4×256**，「256」从记分牌 HUD 飞回（伏笔闭环）；**Δ=0 ⟺ 共线 ⟺ 取等**（印章：「什么时候追平？杆与光合体之时」——取等条件升为一级角色，含反向）；数字淡出成字母：Σ(aᵢt−bᵢ)²≥0 ⟹ Δ≤0（修"特例冒充一般证明"）；∎；字幕：「换成任何数、任何 n——一字不改。」
- （可选 2s 彩蛋：256=16²，63–16–65 直角三角形一闪——爱好者专属）
- 公式 2 · 白闪 1（∎）· 印章 1 · BGM 锚点：120s 抛物线长音 / 127s 256 归位重拍 / 135s ∎ 定音

### P6 星轨+神阶（136–149s，13s）——冻结为系列固定片尾
- **136–141s** 驻留型总结字幕：「**影子，永远不超过杆长。**——柯西·施瓦茨」+ 主公式呼吸金晕
- **141–149s 星轨**：光沿数轴点燃凡→地→天（每阶**一帧缩影闪回**已讲形态，不重亮新公式）；冲向消失点，「神」字浮现，Hölder 暗影 + 1/p+1/q=1（半透明，阴阳互济暗示）；收缩成星、熄灭；字幕：「下一阶：当乘积被推广为 p 次方……」
- 公式 1 · 白闪 0（神阶用金晕）· BGM 锚点：141s 星轨起飞 / 148s 收束
